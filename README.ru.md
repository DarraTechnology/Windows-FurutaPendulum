# Windows FurutaPendulum

Пример управления EtherCAT вращающимся обратным маятником Фуруты в Windows. Приложение считывает энкодер маятника, управляет шаговым приводом рычага через EtherCAT и выполняет подключение, включение, возврат в центр, энергетический разгон и стабилизацию. Интерфейс WinForms и CLI используют один и тот же слой управления и одинаковые блокировки безопасности.

Пример демонстрирует совместную работу счётных IO-слейвов и шаговой оси CiA 402 на одной шине и служит полным справочным примером использования `Darra.EtherCAT.Master`.

## Среда и зависимости

- Windows x64
- .NET Framework 4.7.2 (`net472`)
- NuGet: `Darra.EtherCAT.Master` **2.13.23**

## Перед запуском

- Установите Darra EtherCAT Master официальным установщиком и привяжите драйвер `DarraRT_Eth` к нужному сетевому адаптеру.
- Экспортируйте из GUI файл `config.deni`, соответствующий полевой шине, и поместите его в `EtherCATRestore\` рядом с исполняемым файлом.
- Перед работой на реальном оборудовании убедитесь, что аппаратная аварийная остановка, STO, механические ограничители и освобождение зоны действуют. Не полагайтесь только на программные ограничения.
- Для доступа к драйверу требуются права администратора; запрос UAC при запуске — нормальное явление.

## Сборка

```powershell
dotnet build -c Debug -p:Platform=x64
```

Результат: `bin\x64\Debug\net472\FurutaPendulum.exe`

Без аргументов открывается интерфейс WinForms; с `--cli` включается режим командной строки. Оба режима используют один слой управления.

## Основные команды CLI

| Команда | Назначение |
|---|---|
| `connect` | Подключиться к шине EtherCAT и проверить полевую конфигурацию |
| `enable` | Включить рычаг после выполнения требований безопасности |
| `recenter` | Вернуться в середину хода и выполнить центрирование |
| `swingup` | Автоматический разгон с передачей в стабилизацию при выполнении условий |
| `balance --seconds 30` | Удерживать равновесие 30 секунд |
| `stop` | Управляемая остановка и снятие разрешения |

Пример одиночного запуска:

```powershell
.\bin\x64\Debug\net472\FurutaPendulum.exe --cli "connect; enable; recenter; swingup; balance --seconds 30; stop" --yes
```

Полный список параметров — в `--help`. Все команды движения должны применяться только на реальном оборудовании при действующих мерах безопасности.

## Состояние проверки

| Цикл | Состояние | Примечание |
|---|---|---|
| 1 ms | PASS | Равновесие 30 с завершено, процесс `exit=0`, без `Fault` |
| 500 µs | PASS | Два запуска, в каждом равновесие 30 с, процесс `exit=0`, без `Fault` |
| 250 µs | Проверено, требуется перенастройка | Во время стабилизации возникает `BalanceLost`; 30 с равновесия пока не достигнуто; настройка параметров продолжается |

250 µs не считается пройденным. Период, раскладку PDO и параметры управления нужно проверять как единый набор. После изменения периода повторно экспортируйте `config.deni` и заново выполните проверку подключения, включения, разгона, передачи и стабилизации.
